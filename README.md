# cedar-rest-library

This repository is retired. `CedarHeaderParameters` and `CedarQueryParameters` now live in
[`cedar-model-library`](https://github.com/metadatacenter/cedar-model-library) under their original
`org.metadatacenter.constant` package. The repository is no longer part of the CEDAR build or
release trains.

[![CI](https://github.com/metadatacenter/cedar-rest-library/actions/workflows/ci.yml/badge.svg?branch=develop)](https://github.com/metadatacenter/cedar-rest-library/actions/workflows/ci.yml)
